# 下采样抗混叠与自适应滤波实验
基于 Python + OpenCV + NumPy 实现，包含混叠观察、高斯滤波参数分析、自适应下采样对比

---

## 一、实验内容与目标
1. **Part 1**：生成棋盘格与 Chirp 测试图，对比直接下采样与高斯预滤波下采样的混叠效果，并通过 FFT 频谱在频域验证混叠抑制。
2. **Part 2**：固定下采样倍率 M=4，测试不同 σ 对下采样结果的影响，验证理论参数 `M=1.8, σ=0.45` 的合理性。
3. **Part 3**：基于图像梯度实现自适应下采样，根据局部内容动态调整滤波强度，并与全局固定 σ 下采样进行误差对比。

---

## 二、代码说明
- 图像尺寸统一使用 `50×50`，避免高频棋盘格过度混叠导致图像纯色/全黑。
- 下采样采用块均值方式，保证平滑降采样。
- 高斯滤波用于抗混叠，滤波强度由 σ 控制。
- 自适应部分通过梯度估计局部频率高低，动态分配 σ。

---

## 三、实验结果与分析

### 3.1 Part 1：混叠与抗混叠
- **直接下采样**：高频图像出现明显混叠，表现为波纹、锯齿、结构扭曲。
- **高斯滤波后下采样**：混叠显著消除，图像平滑自然。
- **FFT 频谱**
  - 混叠图像：高频能量折叠，频谱分布杂乱。
  - 抗混叠图像：能量集中在低频中心区域，高频被有效抑制。
- **结论**：直接下采样会造成空间域混叠，其本质是频域高频分量折叠；高斯低通滤波可有效抑制混叠。

### 3.2 Part 2：σ 参数优化与理论值验证
在 M=4 下对不同 σ 进行对比：
- **σ=0.5**：滤波强度不足，仍存在明显混叠。
- **σ=1.0**：混叠基本消除，图像清晰，效果较优。
- **σ=2.0**：滤波偏强，图像开始出现模糊。
- **σ=4.0**：过度模糊，细节大量丢失。

理论值验证（M=1.8，σ=0.45）：
- 无滤波：严重混叠。
- σ=0.45：无混叠且保留较多细节。
- σ=1.8：过度平滑，图像偏糊。

**结论**：σ 存在最优区间，过小无法消除混叠，过大会丢失细节；理论参数 `σ=0.45` 能在抗混叠与细节保留之间达到良好平衡。

### 3.3 Part 3：自适应下采样
- **梯度图**：高频区域梯度大、亮度高，低频区域梯度小、亮度低，可有效区分图像复杂度。
- **全局固定 σ**：整张图统一模糊，高频区域细节丢失严重。
- **自适应 σ**：高频区用小 σ 保细节，低频区用大 σ 抑制混叠，视觉效果更自然锐利。
- **MSE 误差**
  - 全局固定 σ 往往 MSE 更低，因为整体更平滑。
  - 自适应方法在主观清晰度、细节保留上更优，MSE 略高属于正常现象。

**结论**：基于梯度的自适应下采样优于全局固定参数，可根据局部内容动态平衡混叠与细节，提升下采样质量。

---

## 四、整体结论
1. 直接对高频图像下采样会产生明显混叠失真，可通过 FFT 直观观察频域混叠现象。
2. 高斯预滤波是经典有效的抗混叠手段，滤波强度 σ 需合理选择。
3. 实验验证理论参数 `M=1.8, σ=0.45` 合理有效，适合抗混叠下采样。
4. 自适应下采样能够根据图像局部复杂度动态调整滤波强度，在视觉质量与细节保留上优于固定 σ 方法。
