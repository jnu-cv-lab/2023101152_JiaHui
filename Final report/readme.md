# 智能课堂签到与出勤统计系统

## 一、小组成员
孟佳宁、苏小欣、黄敏敏、莫嘉慧、王雪菲

## 二、项目简介
本项目基于 Python 深度学习技术，结合 YOLOv8 人体检测、InsightFace 人脸识别与 Flask 网页服务，设计并实现了一套**智能课堂签到与出勤统计系统**。系统支持摄像头实时人脸签到、手机二维码网页签到双模式，能够自动完成人员识别、签到去重、出勤统计与日志导出，实现课堂考勤自动化、智能化。

## 三、主要功能
- **实时人脸识别签到**：读取摄像头画面，识别人脸自动签到，同一学生多次出镜自动去重，只记录一次有效签到。
- **网页二维码签到**：通过 Ngrok 内网穿透生成外网签到链接，手机扫码即可输入姓名完成签到。
- **双渠道数据合并统计**：人脸签到与网页签到数据自动合并、全局去重。
- **智能出勤统计**：自动计算到场人数、签到人数、出勤率、缺勤人数并生成缺勤名单。
- **陌生人统计**：对课堂陌生人员进行特征去重统计。
- **考勤日志导出**：课程结束可一键导出完整考勤记录。
- **图片考勤**：支持静态课堂图片识别考勤。

## 四、技术栈
Python、YOLOv8、InsightFace、OpenCV、Flask、Ngrok、Tkinter

## 五、运行方式
1. 运行人脸训练代码train1.py
2. 终端开启内网穿透：`ngrok http 8088`
3. 运行主程序：`python main.py`
4. 点击开始考勤，自动识别人脸签到；也可扫码网页签到。
5. 结束后可导出考勤结果。

## 六、核心亮点
- 双签到方式结合，适配课堂多种签到场景
- 全程**自动去重**，避免重复统计
- 自动统计出勤、缺勤、出勤率，数据完整
- 图形化界面，操作简单直观
- 可一键留存考勤记录，方便课后复盘与存档
