## 4. 代码结构与功能说明
### 4.1 自编模块：全局直方图均衡化
```python
def my_equalize_hist(img):
    h, w = img.shape
    hist = np.zeros(256, dtype=np.int32)
    for y in range(h):
        for x in range(w):
            hist[img[y, x]] += 1
    total = h * w
    p = hist / total
    cdf = np.zeros_like(p)
    cdf[0] = p[0]
    for i in range(1, 256):
        cdf[i] = cdf[i-1] + p[i]
    s = np.uint8(255 * cdf)
    out = np.zeros_like(img)
    for y in range(h):
        for x in range(w):
            out[y, x] = s[img[y, x]]
    return out
```
**实现原理：**
1. 统计灰度直方图
2. 计算灰度概率密度
3. 计算累积分布函数 CDF
4. 按公式 `s = 255 × CDF` 映射灰度
5. 逐像素替换，完成均衡化

**不调用 OpenCV 现成函数，完全手动实现。**

# 6. 实验效果分析
本节结合输出的对比图 `result_all.png` 与终端打印的**信息熵、平均梯度**指标，分别对原图、低对比度、高斯噪声、椒盐噪声四类图像的增强效果进行分析。

---

## 6.1 原图（Original）
原图信息熵 **7.87**、平均梯度 **36.0**，作为整体评价基准。

- **HE**：熵略降至 7.71，梯度升至 43.6，对比度小幅提升，但存在轻微信息损失。
- **CLAHE**：熵升至 7.92，梯度大幅升至 53.5，细节增强明显，是原图最优增强方法。
- **均值/高斯/中值滤波**：熵基本不变，梯度下降至 31.7~32.7，图像轻微模糊，对清晰原图无正向作用。
- **锐化**：熵基本不变，梯度升至 43.0，边缘得到强化，效果适中。
- **Filter→HE**：熵 7.71、梯度 39.6，先模糊再均衡，对比度提升但清晰度一般。
- **HE→Filter**：熵回到 7.87，梯度降至滤波水平，均衡效果被模糊抵消。

**结论**：清晰原图下，**CLAHE 效果最优**；滤波类方法只会造成不必要的模糊。

---

## 6.2 低对比度图像（LowContrast）
低对比度图像熵仅 **6.52**、梯度 **14.5**，灰度集中、细节模糊、直方图分布狭窄。

- **HE**：梯度大幅升至 43.8，对比度提升明显，但熵不升反降（6.50），存在过增强与信息丢失。
- **CLAHE**：熵显著提升至 7.38，梯度升至 32.1，对比度自然增强，细节保留远好于 HE。
- **均值/高斯/中值滤波**：熵基本不变，梯度进一步下降，图像更模糊，无法改善对比度问题。
- **锐化**：熵微升、梯度小幅提升，仅轻微强化边缘，对整体发灰效果改善有限。
- **Filter→HE**：梯度升至 39.9，对比度提升明显，无明显过增强，表现稳健。
- **HE→Filter**：梯度回到滤波水平，均衡带来的提升被完全抵消。

**结论**：低对比度场景最优选择为 **CLAHE**；滤波方法无效，**Filter→HE** 是可靠的组合方案。

---

## 6.3 高斯噪声图像（GaussianNoise）
高斯噪声图像熵 **7.88**（信息基本保留），梯度 **79.1**（噪声造成虚假高梯度）。

- **HE / CLAHE**：梯度进一步升高至 89.6 / 128.7，噪声被明显放大，视觉颗粒感严重恶化。
- **均值滤波**：梯度降至 43.7，噪声有所抑制，但模糊程度较重。
- **高斯滤波**：梯度 48.9，去噪效果好且模糊更轻，是高斯噪声的**最优单一滤波方法**。
- **中值滤波**：梯度 47.7，对高斯噪声抑制效果良好，细节保留稳定。
- **锐化**：梯度飙升至 141.7，噪声被极度强化，完全不可用。
- **Filter→HE**：梯度 57.7，先去噪再均衡，兼顾降噪与对比度，整体效果最佳。
- **HE→Filter**：仅达到单纯高斯滤波水平，前期放大噪声无法修复。

**结论**：高斯噪声优先使用**高斯滤波**；组合策略中 **Filter→HE 明显最优**。

---

## 6.4 椒盐噪声图像（SaltPepper）
椒盐噪声图像熵 **7.83**，梯度 **90.5**，黑白噪点造成强烈虚假边缘与高梯度。

- **HE / CLAHE**：梯度维持高位甚至上升，黑白噪点被放大，视觉效果显著变差。
- **均值滤波**：梯度降至 55.0，只能轻微淡化噪点，残留明显。
- **高斯滤波**：梯度 61.2，去噪效果优于均值，但仍无法完全消除黑白点。
- **中值滤波**：熵回升至 7.87，梯度降至 32.7（接近原图），黑白点几乎完全去除，**是椒盐噪声的绝对最优方法**。
- **锐化**：梯度仍高达 86.6，强化噪点边缘，效果极差。
- **Filter→HE**：梯度 75.0，降噪同时提升对比度，优于单纯滤波。
- **HE→Filter**：效果与高斯滤波相当，无法弥补前期噪声放大。

**结论**：椒盐噪声场景**中值滤波效果显著优于其他所有方法**。

---

## 6.5 整体方法适用性总结
1. **低对比度增强**：**CLAHE ＞ 全局 HE**
2. **高斯噪声去除**：**高斯滤波 ＞ 中值滤波 ＞ 均值滤波**
3. **椒盐噪声去除**：**中值滤波 ＞ 高斯滤波 ＞ 均值滤波**
4. **锐化**：仅适用于干净原图，噪声图中会严重恶化效果
5. **组合策略**：**Filter→HE（先滤波再均衡）** 整体最优，能同时应对噪声+低对比度；**HE→Filter 效果较差**

# 7. 实验结论

1. **低对比度图像**
   全局 HE 与 CLAHE 均可有效提升对比度，但 HE 易出现过增强并损失信息；**CLAHE 在提升对比度的同时能更好保留细节，综合效果最优**。滤波类方法无法改善灰度集中问题，反而会使图像更模糊。

2. **高斯噪声图像**
   直接进行均衡化或锐化会显著放大噪声，使图像质量恶化。**高斯滤波对高斯噪声抑制效果最好，且细节保留优于均值滤波**；中值滤波也有一定去噪能力，但整体略逊于高斯滤波。

3. **椒盐噪声图像**
   椒盐噪声为典型脉冲噪声，**中值滤波能够几乎完全去除黑白噪点，同时恢复正常梯度水平，效果显著优于均值与高斯滤波**，是处理该类噪声的首选方法。

4. **锐化方法**
   仅适用于无噪声的清晰图像，可有效提升边缘与细节；在噪声图像中锐化会强化噪声、大幅抬升梯度，严重降低视觉质量，不建议直接使用。

5. **组合处理策略**
   **先滤波去噪、再直方图均衡（Filter→HE）** 能够兼顾噪声抑制与对比度增强，适合退化较复杂的图像；而先均衡再滤波（HE→Filter）会先放大噪声，后续难以完全修复，整体效果较差。

6. **方法适用性总结**
   - 低对比度增强：**CLAHE 最优**
   - 高斯噪声去除：**高斯滤波最优**
   - 椒盐噪声去除：**中值滤波最优**
   - 噪声+低对比度复合退化：优先使用 **Filter→HE 组合流程**
