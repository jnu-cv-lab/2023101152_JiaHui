# 图像局部频率估计：FFT 95%能量法与空域梯度法对比
## 1. 实验目的
- 对图像分块，使用**FFT 计算包含 95% 能量的最高频率**，作为局部频率的精确参考。
- 使用**空域梯度能量法**实现局部最高频率的快速近似估计。
- 对比两种方法结果，通过相关系数、MAE、MSE 分析一致性。
- 验证空域梯度可作为局部真实频率的有效近似，用于滤波器宽度等参数估计。

## 2. 实现方法
### 2.1 FFT 95% 能量最高频率
1. 对图像块做 2D-FFT 并 fftshift 中心化。
2. 计算能量谱 `energy = |FFT|²`，按**频率从小到大**累加能量。
3. 找到累积能量 ≥ 95% 时对应的最大径向频率。
4. 归一化到 `[0,1]` 作为该块最高频率。

### 2.2 空域梯度 95% 能量频率近似
1. 使用**中央差分**计算 x/y 方向梯度，得到梯度幅值。
2. 定义梯度能量 `grad_energy = grad_mag²`，与 FFT 能量定义对齐。
3. 按梯度能量从大到小累加，取覆盖 95% 梯度能量的最大梯度。
4. 归一化映射到 `[0,1]`，作为空域近似频率。

### 2.3 评价指标
- 皮尔逊相关系数 `corr`：衡量线性相关程度
- 平均绝对误差 `MAE`
- 均方误差 `MSE`

- 梯度可作为局部频率的快速近似，计算效率高，适合实时滤波器宽度估计。
- 实验验证了“梯度—局部最高频率”的关联关系，符合作业要求与理论分析。
