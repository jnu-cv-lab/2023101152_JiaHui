# 问题问答
## 问题1：什么是特征点？
1. **特征点主要分布在图像的哪些区域？**
结合实验中 ORB、SIFT 检测结果来看：特征点集中分布在物体边缘、四角角点、文字区域、图案纹理复杂处、物体交界轮廓；而图片纯色背景、空白平面、光滑无变化的大面积平整区域，特征点数量极少甚至没有。

2. **为什么文字、角点、纹理丰富区域容易产生特征点？**
角点存在灰度与方向突变，局部窗口移动会产生明显像素变化；文字与复杂纹理灰度变化频繁、边缘密集，局部差异显著；此类区域特征唯一性强，算法易提取稳定且可重复检测的关键点。

3. **为什么大面积平坦区域通常没有明显特征点？**
平坦纯色区域像素灰度均匀、变化微弱，窗口平移或旋转后无明显差异，缺少独特边缘与纹理信息，不满足特征点检测条件，因此几乎无特征点产出。

---

## 问题2：什么是特征描述子？
1. **描述子和关键点有什么区别？**
关键点是图像中稳定的局部位置，记录坐标、尺度、方向等空间信息；描述子为关键点邻域的特征向量，用于表征局部纹理与灰度分布细节。

2. **为什么只知道关键点位置还不够，还需要描述子？**
仅依靠坐标无法区分不同特征，易出现误匹配。描述子可量化局部特征差异，依靠特征相似度，完成跨图像的正确匹配。

3. **ORB 描述子的输出维度是多少？**
ORB 描述子默认输出维度为 32 维。

4. **ORB 描述子为什么是二进制描述子？**
ORB 通过邻域像素灰度对比生成 0、1 二进制编码，占用内存小、运算简单，匹配速度更快，适配实时视觉任务。

---

## 问题3：为什么 ORB 使用 Hamming distance？
1. **ORB 描述子的基本结构是什么？**
ORB 为二进制描述子，以关键点为中心，对邻域像素做灰度比较，生成固定长度的 0/1 比特向量，结构紧凑，具备旋转不变性。

2. **Hamming distance 衡量的是什么？**
汉明距离统计两组二进制描述子对应位置不同比特的数量，数值越小，特征相似度越高。

3. **为什么 ORB 不使用普通欧氏距离进行匹配？**
欧氏距离适用于浮点型向量，无法适配二进制编码；汉明距离运算简洁高效，更适合 ORB 二进制描述子的快速匹配。

---

## 问题4：ORB 为什么对旋转、平移和一定尺度变化具有鲁棒性？
1. **为什么描述子在关键点局部邻域中计算，所以对平移比较鲁棒？**
描述子仅依赖关键点小范围邻域信息，图像整体平移不会改变邻域纹理内容，描述子保持稳定，具备平移鲁棒性。

2. **ORB 如何通过方向估计增强旋转鲁棒性？**
通过计算邻域灰度质心确定关键点主方向，生成描述子时依据主方向旋转校正，消除旋转带来的特征偏差。

3. **ORB 如何通过图像金字塔增强尺度鲁棒性？**
构建多层图像金字塔，在不同缩放层级检测特征，目标发生尺度变化时，可在对应层级匹配到有效特征。

4. **ORB 是否能完全抵抗透视变换？为什么？**
不能。透视变换会扭曲局部纹理与邻域结构，破坏特征稳定性，ORB 仅适配平移、旋转、尺度变换，无法抵抗复杂透视畸变。


---
## 问题 5：为什么初始匹配中会有错误匹配？
1. **错误匹配通常出现在什么情况下？**
错误匹配常出现在背景复杂、纹理重复、物体边缘相似、大面积相近色块，以及不同位置局部图案高度相似的区域。

2. **重复纹理、相似图案、背景干扰为什么会导致错误匹配？**
重复纹理和相似图案的局部灰度、细节高度接近，生成的描述子相似度很高；背景干扰会产生大量无关噪声特征，算法难以区分真假目标特征，进而造成跨区域错误匹配。

3. **是否匹配距离越小就一定是正确匹配？为什么？**
不一定。匹配距离仅代表描述子数值相似度，若图像存在大量相似纹理，无关特征的描述子也会差距很小、距离很近，依然会产生误匹配，需要 RANSAC 等算法进一步筛选。

---
## 问题 6：RANSAC 的作用是什么？
1. **RANSAC 是如何剔除错误匹配的？**
RANSAC 随机选取少量匹配点求解单应矩阵，利用该矩阵投影校验所有匹配对，剔除不符合几何变换规律的匹配，保留符合映射关系的匹配点，迭代筛选最优模型。

2. **RANSAC 使用的依据是描述子相似性，还是几何一致性？**
依据**几何一致性**。不依赖描述子相似度，依靠目标前后的空间投影、变换约束筛选匹配。

3. **什么是 inlier？**
inlier 即内点，符合真实几何变换模型、匹配正确的特征点对，是有效正确匹配。

4. **什么是 outlier？**
outlier 即外点，违背几何变换关系的错误匹配点对，属于误匹配、无效匹配。

5. **为什么 RANSAC 后的匹配线明显更合理？**
RANSAC 剔除了杂乱无规律的外点误匹配，只保留符合物体透视投影关系的内点，匹配连线符合物体空间位置对应关系，排布规整、逻辑合理。

---
## 问题 7：Homography 的意义是什么？
1. **Homography 描述了两幅图像之间的什么关系？**
单应矩阵描述两张图像同一平面场景之间的**透视投影变换关系**，可以实现平面点在两幅图之间的相互映射。

2. **为什么 box.png 和 box_in_scene.png 适合使用 Homography？**
目标物体为平面纸板，两幅图像中的目标属于同一平面，视角变化以透视变换为主，满足单应矩阵的平面映射前提。

3. **Homography 更适合平面物体还是立体物体？为什么？**
更适合**平面物体**。单应矩阵假设物体处在同一平面，平面物体无深度差异，符合投影变换模型；立体物体存在深度信息，不满足平面约束。

4. **如果场景中物体不是平面，Homography 可能会出现什么问题？**
立体物体存在深度落差，不满足平面假设，会导致单应矩阵拟合错误，出现点位投影偏移、目标框错位、匹配筛选失效、定位不准等问题。

---
## 问题 8：SIFT 和 ORB 有什么区别？
1. **ORB 描述子和 SIFT 描述子的结构有什么不同？**
ORB 是二进制描述子，由 0 和 1 组成；SIFT 是浮点型描述子，由浮点数组成。

2. **ORB 为什么使用 Hamming distance？**
ORB 输出二进制比特串，Hamming 距离只对比比特位是否不同，计算极快。

3. **SIFT 为什么使用 L2 distance？**
SIFT 是浮点向量，L2 距离能准确衡量浮点特征间的欧式差异，符合匹配需求。

4. **SIFT 为什么通常比 ORB 更稳定？**
SIFT 基于梯度构建，对旋转、尺度、光照更稳定，特征区分度更高。

5. **ORB 为什么通常比 SIFT 更快？**
ORB 二进制计算简单，匹配只需位运算，比 SIFT 浮点运算速度快很多。

6. **在本实验中，SIFT 和 ORB 哪个效果更好？**
本实验中 SIFT 效果更好，匹配更精准、内点比例更高、定位更稳定；ORB 速度更快，但在特征点过多时易出现定位错误。


---

## 问题 9：SIFT 是否抗透视变换？
1. **SIFT 主要抗哪些变化？**
SIFT 主要抵抗尺度缩放、旋转变化、光照明暗变化与少量噪声干扰。

2. **SIFT 是否严格抗透视变换？**
不能严格抵抗透视变换，仅具备有限适应性，无法完全消除透视畸变带来的影响。

3. **为什么 SIFT 对小范围视角变化有一定鲁棒性？**
SIFT 依靠图像金字塔实现尺度不变性，通过梯度方向确定主方向。小视角变化不会严重破坏局部纹理与梯度信息，因此特征仍可稳定匹配。

4. **为什么大角度透视变化下 SIFT 仍可能失败？**
大角度透视会扭曲物体局部轮廓与纹理结构，改变邻域像素分布，导致描述子差异增大，最终造成特征匹配失效。

5. **在本实验中，真正处理整体透视变化的是 SIFT/ORB，还是 RANSAC + Homography？**
真正处理整体透视变化的是 RANSAC+Homography；SIFT 与 ORB 仅负责局部特征提取，不具备全局透视矫正能力。

# 实验总结
本实验围绕图像局部特征匹配展开，完成了 ORB 与 SIFT 特征提取、特征匹配、误匹配剔除及平面目标透视定位等完整任务。通过调整 ORB 特征数量完成对照实验，同时对比两种经典特征算法的性能差异，结合实验现象理解特征检测与图像变换的基础原理。

ORB 特征匹配流程为：检测图像关键点并计算二进制描述子，利用汉明距离完成暴力匹配，得到初始匹配结果。初始匹配存在大量误匹配，需依靠 RANSAC 算法结合单应矩阵完成优化。

单应矩阵可以表征平面图像间的透视投影关系，RANSAC 通过迭代筛选符合几何约束的内点，剔除错误外点，依靠最优变换矩阵完成关键点映射，实现目标框选与精准定位。

实验中发现，特征数量过多会引入冗余弱特征，加剧误匹配，造成单应矩阵求解异常、目标定位偏移；重复纹理与复杂背景也会大幅降低匹配质量。

本次实验表明，特征匹配鲁棒性代表算法对平移、旋转、尺度及小视角变化的适应能力。ORB 计算高效，适合实时场景；SIFT 特征区分度高、稳定性更强。仅依靠描述子匹配存在缺陷，结合几何约束筛选，才能有效提升目标检测与特征匹配的可靠性。
