# 图像下采样与插值恢复实验
---

# 1. 实验目的
1. 实现灰度图像的读取、显示与基本预处理。
2. 实现两种下采样方式：**无预滤波直接下采样**、**高斯平滑后下采样**，并对比混叠现象。
3. 使用**最近邻、双线性、双三次**三种插值方法将缩小图像恢复至原始尺寸。
4. 在空间域对原图与恢复图像进行对比，计算并分析 **MSE** 与 **PSNR**。
5. 通过**二维傅里叶变换（FFT）**观察频谱，分析下采样与插值对高频成分的影响。
6. 通过**二维离散余弦变换（DCT）**分析系数分布，统计低频区域能量占比，比较不同恢复方法的能量差异。
7. 从频域角度解释混叠成因、高斯滤波作用及插值算法的局限性。

# 4. 算法原理简介
## 4.1 下采样与混叠
直接下采样会使高于奈奎斯特频率的高频成分无法正确表示，形成**混叠（锯齿、伪影）**。
高斯滤波相当于低通滤波，可预先去除高频，避免混叠，但会损失细节。

## 4.2 插值恢复
- **最近邻插值**：计算简单，块效应与锯齿明显。
- **双线性插值**：4 邻域加权，平滑但偏模糊。
- **双三次插值**：16 邻域高阶拟合，细节保留最好，PSNR 最高。

## 4.3 傅里叶变换（FFT）
将图像转为频域：
- **中心**：低频（亮度缓慢变化区域）
- **外围**：高频（边缘、纹理、噪声、混叠）
对数幅度谱用于增强弱高频分量，便于观察。

## 4.4 离散余弦变换（DCT）
图像能量高度集中于 DCT 左上角低频系数。
通过 **低频区域能量 / 总能量** 可量化高频丢失程度：比值越高，高频丢失越严重。

# 6. 详细实验结果与分析

## 6.1 空间域结果分析
1. **直接下采样恢复图像**
   边缘相对锐利，但存在明显**锯齿、伪轮廓、混叠失真**。原因是未滤除高频，下采样引发频率混叠。

2. **高斯下采样恢复图像**
   无明显锯齿，整体平滑自然，但细节与纹理清晰度下降。原因是高斯滤波抑制了高频，消除混叠但丢失真实细节。

3. **插值方法对比**
   - **最近邻**：块效应严重，阶梯化明显，PSNR 最低。
   - **双线性**：过渡平滑，无明显块效应，但存在模糊。
   - **双三次**：细节保留最好，边缘自然，PSNR 最高。

4. **下采样倍数影响**
   1/4 下采样恢复质量显著差于 1/2 下采样。缩小倍数越大，信息丢失越多，MSE 上升、PSNR 下降。

---

## 6.2 傅里叶变换（FFT）频谱详细分析
### 6.2.1 频谱读图规则
- **中心亮**：低频能量强，对应图像大块平滑区域。
- **四周亮**：高频能量强，对应边缘、纹理、噪声、混叠。
- **对数幅度谱**：放大微弱高频，便于观察混叠与细节丢失。

### 6.2.2 逐图频谱分析
1. **原图频谱**
   中心低频高度集中，外围高频连续且丰富，高低频齐全，信息完整无失真。

2. **直接下采样频谱**
   中心低频基本保留，但**外围高频能量未被抑制**，并出现异常对称亮纹与毛刺。
   这是**频率混叠**在频域的典型表现，对应空间域的锯齿与伪影。

3. **高斯下采样频谱**
   中心低频保留，但**外围高频能量显著衰减、整体变暗**，频谱形态更紧凑圆钝。
   高斯滤波起到低通作用，高频被滤除，因此无混叠，但图像细节丢失。

4. **双线性插值恢复后频谱**
   低频部分看似恢复，但**外围高频依旧严重缺失、暗淡**。
   插值本质是平滑拟合，**无法重建真实高频信息**，下采样丢失的高频不可恢复。

### 6.2.3 不同下采样倍数频谱差异
- **1/2 下采样**：高频残留较多，混叠较轻。
- **1/4 下采样**：奈奎斯特频率更低，高频损失或混叠更严重，频谱更向中心收缩。

### 6.2.4 频谱物理意义总结
- 直接下采样：高频未滤除 → **混叠干扰**。
- 高斯下采样：高频被滤除 → **无混叠但模糊**。
- 插值恢复：**仅能重构低频，无法恢复高频**。
- 下采样倍数越大，高频截止越低，图像质量下降越明显。

---

## 6.3 DCT 变换详细分析
1. **原图 DCT**
   左上角低频系数能量强，高频区域有合理分布，低频能量占比适中，细节丰富。

2. **恢复图像 DCT**
   高频系数能量显著减弱，**低频能量占比明显高于原图**，说明高频大量丢失。

3. **插值方法差异**
   - **最近邻**：高频几乎消失，低频占比最高，细节损失最严重。
   - **双线性**：高频保留中等，低频占比次之。
   - **双三次**：高频保留最多，低频占比最低，最接近原图分布。

4. **下采样方式影响**
   高斯下采样恢复图低频占比 **高于** 直接下采样，说明高斯滤波进一步压制高频。

5. **下采样倍数影响**
   1/4 下采样高频损失比 1/2 更严重，低频占比更高，与空间域、PSNR 结论一致。

---

# 7. 综合结论
1. **直接下采样会引发混叠**，因高频未被滤除，超出奈奎斯特频率导致伪影。
2. **高斯预滤波可有效抑制混叠**，但会牺牲高频细节，使图像偏模糊。
3. **插值只能平滑填充，不能创造真实高频信息**，缩小再放大必然存在质量损失。
4. **双三次插值效果最优**，PSNR 最高、高频保留最多、视觉最自然；最近邻效果最差。
5. **下采样倍数越大，高频损失/混叠越严重**，恢复质量越差。
6. **FFT 与 DCT 从频域共同证明**：
   下采样的核心损伤是**高频混叠或丢失**；高斯滤波加剧高频损失；插值仅能恢复低频结构。
7. 空间域指标（MSE/PSNR）与频域特征高度一致，可综合评价图像缩放与恢复质量。
