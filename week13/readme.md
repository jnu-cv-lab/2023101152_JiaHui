# Sinusoidal PE vs RoPE 实验报告 README
## 一、实验运行结果汇总
### 1. 正弦位置编码（Sinusoidal Position Encoding）实现结果
输入词嵌入 `emb` 维度：`torch.Size([1, 6, 8])`
输出 $E+\rm{pos}$ 结果维度：`torch.Size([1, 6, 8])`
实现逻辑：预生成三角函数位置编码矩阵，**采用加法形式：$\boldsymbol{H}=\boldsymbol{E}+\boldsymbol{PE}$**，将独立位置向量叠加至原始词嵌入。

### 2. 二维向量旋转实现结果
基准原始向量：`[1. 0.]`
- 位置$\boldsymbol{pos=1}$旋转后：`[0.5403023  0.84147096]`
- 位置$\boldsymbol{pos=3}$旋转后：`[-0.9899925  0.14112  ]`
原理：将2维向量等效复平面复数，利用 $z'=z\cdot e^{i\cdot pos\cdot\theta}$ 旋转变换，位置数值变化直接改变向量指向。

### 3. 高维RoPE实现结果
输入`emb`：`torch.Size([1, 6, 8])`，RoPE旋转输出：`torch.Size([1, 6, 8])`
实现规则：高维特征两两分组拆分为多组二维向量，每组使用独立频率分别旋转，最后拼接还原原始维度。

### 4. E+pos 与 RoPE 输入融合方式对比
|编码方式|融合逻辑|样本数值（取前3维）|
| ---- | ---- | ---- |
|E+pos(SinPE)|词嵌入$\boldsymbol E$ + 独立预计算位置向量$\boldsymbol {PE}$，向量加法融合|原始：`[-1.2586, -0.5865,  0.8243]`<br>相加后：`[-1.2586,  0.4135,  0.8243]`|
|RoPE|对原始$\boldsymbol E$几何旋转，无额外位置向量、无加法偏移|旋转后：`[-1.2586, -0.5865,  0.8243]`|
> 现象说明：SinPE因加法造成元素数值偏移；RoPE只改变向量方向，不通过加常数篡改特征幅值。

### 5. RoPE相对位置数值验证
- 相同相对间距$3$：$(2,5)$内积$=12.4362$、$(12,15)$内积$=12.4362$，绝对位置不同、间距一致则内积几乎完全相等；
- 不同相对间距$4$：$(0,4)$内积$=12.4016$，距离改变后内积明显变化；
**实验结论**：RoPE的Q/K内积仅依赖token间相对距离，与绝对位置下标无关，天然具备相对位置编码属性。

## 二、原理问题解答
### 1. Transformer 为什么需要位置编码
Self-Attention运算具备**序列置换不变性**，打乱输入token顺序，注意力输出结果不变，模型无法感知词语时序。自然语言、时序数据高度依赖语序语义，必须通过位置编码向词嵌入注入序列位置信息。

### 2. Sinusoidal 正弦位置编码生成规则
$$
\begin{cases}
PE(pos,2i)=\sin\left(pos\cdot \dfrac{1}{10000^{\frac{2i}{d_{model}}}}\right)\\
PE(pos,2i+1)=\cos\left(pos\cdot \dfrac{1}{10000^{\frac{2i}{d_{model}}}}\right)
\end{cases}
$$
提前预分配最大序列长度的编码表，最终采用 $\boldsymbol{E+PE}$ 加法嵌入位置信息，属于**绝对位置编码**。

### 3. $E+\rm{pos}$存在内容与位置混杂问题
词嵌入$\boldsymbol E$承载语义内容、$\boldsymbol {PE}$承载位置信息，逐元素直接相加造成数值混叠，单个数值无法区分来源是词义还是位置；
注意力内积展开：$(E_p+P_p)(E_q+P_q)^T=E_pE_q^\top+E_pP_q^\top+P_pE_q^\top+P_pP_q^\top$，交叉项杂乱，无法天然解耦相对位置关系；同时预定义最大序列长度，超长文本无法外推编码。

### 4. RoPE摒弃加法，改用几何旋转嵌入位置
RoPE不构造独立位置向量，把特征向量两两分组等效复数，利用复数乘法实现平面旋转：位置$pos$对应旋转角，位置信息仅改变向量**方向**、保留向量模长（原始内容幅值不变），通过几何约束实现位置与内容解耦。

### 5. RoPE仅作用于Q、K，不作用V
注意力计算公式：$\mathrm{Attn}=\mathrm{softmax}(\tfrac{QK^\top}{\sqrt d})V$，注意力相似度完全由$QK^\top$决定，仅需在Q、K中注入位置即可约束位置相关性，Value保留原始语义特征无需旋转，节约计算开销。

### 6. RoPE的QK点积天然携带相对位置信息
设$Q_p$为$p$位置旋转Query，$K_q$为$q$位置旋转Key，复数形式：$Q_p=q\cdot e^{ip\omega},K_q=k\cdot e^{iq\omega}$，共轭内积：
$$Q_p\cdot K_q^* = qk^*\cdot e^{i(p-q)\omega}$$
内积结果仅由相对距离$\Delta=p-q$决定，消除绝对位置的影响。

### 7. Attention Score天然自带相对位置约束
注意力打分 $\mathrm{score}_{p,q}\propto\mathrm{Re}(Q_pK_q^*)$，打分数值仅由token间隔距离决定，近距离耦合权重高、远距离权重低；无需额外引入偏置项，旋转的数学结构自动把相对位置规律嵌入注意力权重。

## 三、RoPE相比E+pos正弦PE更巧妙的原因
1. **编码属性优势**：正弦PE是绝对位置编码，RoPE天然相对位置编码，贴合注意力依赖词语间隔的语义规律；
2. **特征解耦优势**：E+pos加法混叠内容与位置，RoPE通过旋转区分向量方向（位置）和模长（语义），实现几何解耦；
3. **外推能力优势**：正弦PE固定最大长度，超出预训练长度无编码；RoPE实时计算旋转角，支持任意超长序列外推；
4. **数学适配优势**：RoPE数学形式完美匹配QK内积运算，相对位置特性由公式天然生成，无需额外构造交叉项。
