# 作业1：YCbCr 色彩空间下采样与插值实验
## 一、实验背景与原理
### 1.1 YCbCr 色彩空间
YCbCr 是一种将**亮度（Y）** 与**色度（Cb/Cr）** 分离的色彩空间：
- **Y 通道**：亮度信息，决定图像的明暗，人眼对其变化高度敏感；
- **Cb 通道**：蓝色分量与亮度的差值；
- **Cr 通道**：红色分量与亮度的差值；
- 人眼对色度信息不敏感，因此可对 Cb/Cr 通道下采样以压缩数据，同时不显著影响视觉效果。

### 1.2 下采样与插值
- **下采样**：降低 Cb/Cr 通道的分辨率（本次实验采用 2 倍下采样，即 4:2:0 格式），减少数据量；
- **插值恢复**：通过算法将下采样后的 Cb/Cr 通道恢复至原尺寸，本次使用**双线性插值（INTER_LINEAR）**，兼顾效果与效率。

### 1.3 PSNR 评价指标
PSNR（峰值信噪比）用于量化重建图像与原图的差异：
- 公式：$PSNR = 20 \times \log_{10}(\frac{255}{\sqrt{MSE}})$，其中 $MSE = \frac{1}{H×W×C}\sum_{i,j}(I_{ori}(i,j)-I_{recon}(i,j))^2$；
- 数值越高表示图像质量越好：
  - PSNR ≥ 40 dB：几乎无视觉差异；
  - 30 ≤ PSNR < 40 dB：轻微差异，人眼难以察觉；
  - PSNR < 30 dB：可明显感知失真。
