# 几何变换实验报告
**基于 OpenCV 实现相似变换、仿射变换、透视变换及文档透视校正**

---

## 实验目的
1. 理解**相似变换、仿射变换、透视变换**的数学原理与实现方式，手动构造变换矩阵完成图像变换。
2. 观察三类变换对测试图中**直线、平行线、垂直线、圆**四类几何元素的影响，总结几何性质变化规律。
3. 实现倾斜拍摄的A4纸文档的透视校正，验证变换在实际场景中的应用效果。

## 实验环境
- 编程语言：Python
- 核心库：OpenCV(cv2)、NumPy、Matplotlib
- 工具：自制测试图（包含矩形、圆、平行线、垂直线）、实拍A4纸文档图

## 实验原理
### 1. 相似变换
- 定义：由**旋转、缩放、平移**组合而成的刚体变换，是仿射变换的特例。
- 变换矩阵（2×3）：
$$
\begin{bmatrix}
s\cos\theta & -s\sin\theta & t_x \\
s\sin\theta & s\cos\theta & t_y
\end{bmatrix}
$$
- 核心：保持图形**形状不变**，仅改变大小和位置。

### 2. 仿射变换
- 定义：由**线性变换+平移**组成，变换矩阵为2×3。
- 核心：**直线→直线、平行线保持平行**，但形状、比例、垂直关系可能改变。

### 3. 透视变换
- 定义：基于中心投影原理，适用于平面倾斜/透视场景，变换矩阵为3×3。
- 核心：**直线仍为直线**，但**平行线不再平行**，是文档校正的核心方法。

### 4. 核心函数
- `cv2.warpAffine`：实现相似变换、仿射变换
- `cv2.warpPerspective`：实现透视变换

## 实验内容与步骤
### （一）测试图几何变换实验
1. 制作测试图：绘制包含矩形、标准圆、水平/垂直平行线、相互垂直的直线的标准图像。
2. 手动构造变换矩阵：
   - 相似变换：设置旋转30°、缩放0.8、中心平移
   - 仿射变换：自定义线性变换系数+平移量
   - 透视变换：自定义3×3投影矩阵
3. 执行变换：调用OpenCV函数完成三类变换，保存结果图。
4. 几何性质判断：逐一观察直线、平行线、垂直线、圆的变化。

### （二）A4纸文档校正实验
1. 采集图像：倾斜拍摄带有文字、表格的A4纸文档。
2. 交互选点：通过鼠标点击选取文档**左上、右上、右下、左下**四个角点。
3. 计算变换矩阵：根据角点计算透视变换矩阵。
4. 文档校正：执行透视变换，将倾斜文档校正为正视图，对比原图、仿射变换、校正结果。
5. 效果评估：观察校正后文字、表格是否变形，判断校正效果。

## 实验结果与分析
### 1. 三类变换几何性质对比表
| 几何性质 | 相似变换 | 仿射变换 | 透视变换 |
|----------|----------|----------|----------|
| 直线是否保持直线 | 是 | 是 | 是 |
| 平行线是否保持平行 | 是 | 是 | 否 |
| 两条垂直线是否垂直 | 是 | 否 | 否 |
| 圆是否保持为圆 | 是 | 否（变为椭圆） | 否（变为椭圆/不规则圆） |

### 2. 文档校正实验结果
- 原图：A4纸倾斜拍摄，文字、表格存在透视畸变，阅读困难。
- 仿射变换结果：无法完全校正倾斜，文字仍存在拉伸变形，校正效果差。
- 透视+相似校正结果：文档完全摆正，**文字、表格无变形、无拉伸**，边缘笔直，阅读清晰。
- 个人评价：校正效果非常满意，完全满足文档识别、阅读需求。

## 实验总结
1. 三类变换的约束性依次降低：**相似变换 > 仿射变换 > 透视变换**。
2. 相似变换适合保持形状的场景；仿射变换适合平行关系不变的场景；**透视变换是倾斜平面校正的最优方案**。
3. 手动构造变换矩阵能深入理解变换原理，鼠标交互选点+透视变换可高效实现文档自动校正，实用性极强。
4. 实验验证了几何变换在计算机视觉中的核心作用，为后续图像校正、目标检测等任务奠定基础。
